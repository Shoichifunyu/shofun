### STEP1
- 自分で考えて解く
  - 問題文
    - 2分木が2つ与えられる
    - この2分木を統合する問題
    - 2つのノードが重複する場合、それぞれのノードの値を足して、それを統合したノードの値とする
    - そうでなければ、子のないノードが追加される
    - この統合プロセスはそれぞれの木の根(root)から始める必要がある
  - 問題文考察
    - 根の数から順にそれぞれの二分木のノードの値を足していく
    - 仮に、片方の二分木のノードが存在しない場合は、もう片方の二分木のノードがあるかをチェックし、あれば値を設定する
    - 両方の二分木のノードが存在しない場合は、何も設定しない
    - TreeNode型が与えてれているが、統合用に初期化したTreeNodeを用意し、それに個々の値を追加していく方がシンプルそう
 ```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        def sum_node(add_node: TreeNode, added_node: TreeNode):
            # nodeがNoneかどうかのチェック
            if add_node is None:
                return added_node
            # Noneでない場合新nodeにnodeの値を加算
            added_node.val += add_node.val
            # それぞれのnodeに子がいる場合、その子の値も新nodeの子に加算
            if add_node.left is not None:
                added_node.left = TreeNode()
                sum_node(add_node.left, added_node.left)
            if add_node.right is not None:
                added_node.right = TreeNode()
                sum_node(add_node.right, added_node.right)
            return added_node
       
        new_node = TreeNode()
        if root1 is not None:
            new_node = sum_node(root1, new_node)
        if root2 is not None:
            new_node = sum_node(root2, new_node)
        return new_node
```
- 結果はWA
  - 先頭の要素は足し合わせられているが、それ以降が足し合わせられていない

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        def merge_nodes(node1: Optional[TreeNode], node2: Optional[TreeNode]):
            if node1 is None and node2 is None:
                return None
            if node1 is None:
                node1, node2 = node2, node1
                
            merged_node = TreeNode(val=node1.val)
            if node2 is None:
                merged_node.left = merge_nodes(node1.left, None)
                merged_node.right = merge_nodes(node1.right, None)
            else:
                merged_node.val += node2.val
                merged_node.left = merge_nodes(node1.left, node2.left)
                merged_node.right = merge_nodes(node1.right, node2.right)
            return merged_node
        return merge_nodes(root1, root2)
