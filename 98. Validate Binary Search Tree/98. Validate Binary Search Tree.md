### STEP1
- 何も見ずに解いてみる
  - 2分探索木の有効性チェックの問題
    - あるツリーに対して、左側のサブツリーには**そのツリーのノードよりも低い数字しか含まれてはならない**
    - あるツリーに対して、右側のサブツリーには**そのツリーのノードよりも高い数字しか含まれてはならない**
    - 左側・右側のサブツリー共に2分探索木である必要がある
- 解き方を考える
  - 上記の問題の制約を見るに、ルート(根)は全体の二分探索木の各値の中間にあたる値と想定される
  - ルートに対して、左側のノード、ないしリーフは必ず低い値でないとならない。仮に左側のノードだった場合は、再帰的にこの制約が生じる
  - ルートに対して、右側のノード、ないしリーフは必ず高い値でないとならない。仮に右側のノードだった場合は、再帰的にこの制約が生じる
  - つまり、TreeNode.valとTreeNode.left.valを比較し、前者が高ければtrue, 低ければfalse
  - TreeNode.valとTreeNode.right.valを比較し、前者が低ければtrue, 高ければfalse
  - ...と思ったがそうシンプルではなさそう。ルートから見て左半分の数値(個々の)が、ルートから見て右半分の数値以上のものがあってはならない。
  - つまり、各に分木の検証を行いつつ、最後に左半分の最大値が右半分の最小値よりも小さいことをチェックする必要がある
  - ...と思ったが、ルートから見て左半分の最大値と右半分の最小値の比較では足りない。右半分にルートの値も含める必要がある。
  - ここで詰まってしまった

    ```py
    class Solution:
        def isValidBST(self, root):
            queue = deque([(float('-inf'), float('inf'), root)])
            while queue:
                lower, upper, node = queue.popleft()
                if node.val <= lower or node.val >= upper:
                    return False

                if node.left:
                    queue.append((lower, node.val, node.left))
                if node.right:
                    queue.append((node.val, upper, node.right))
                
            return True
    ```
  - 毎度おなじみのdequeを使う方法
    - 各appendではtuple型の3つの要素(lower, upper, node)をdequeに追加する。(初期値は`deque([(float('-inf'), float('inf'), root)])`)
    - 入れる要素はnode.leftかnode.rightかによって変わり、node.leftならnode.valより低い値になるはずなので、upperにnode.valを、node.rightなら逆にnode.valより高い値になるはずなのでlowerにnode.valを代入する
