### STEP1
- 何も見ずに解く
  - 二分木の問題
  - 木の深さ(最深)を解く
  - 制約
    - 各ノードの数は0~10^4
    - ノードの値は-100~100の間
  - 例えばInputが[3,9,20,null,null,15,7]であれば、Outputは3、Inputが[1,null,2]であれば、Outputは2
    - 先頭の要素は常に親、続いて親から派生する子(2要素)、続いてその子から派生する孫(2要素)...
    - 下に行くにつれて、親から(その親の)子の最短距離は2^(n-1)要素分となる(nはその木の深さ)
    - これを利用し、要素の数からその木の深さを求める
    - とおもったが、TreeNodeの構造上、それは簡単に求められそう(TreeNode型ではなく、List型と勘違いしていた。
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        def perDepth(node: Optional[int], node_depth: int) -> int:
            if node is None:
                return node_depth
    
            node_depth = max(perDepth(node.left, node_depth), perDepth(node.right, node_depth))
            node_depth += 1
            return node_depth

        node_depth = 0
        depth_result = perDepth(root, node_depth)

        return depth_result
```

    - recursion解法とstack解法の違いについてGeminiに聞いてみる

| アプローチ | 別名/方式 | 最適なケース |
| :--- | :--- | :--- |
| **下から上** | Iterative (反復処理) | 制約 $N$ が非常に大きい（再帰の深さが深くなりすぎる）場合、または**実行速度が最優先**の場合。 |
| **上から下** | Memoization (メモ化再帰) | **再帰的な定義が複雑**で、反復処理の実装が難しい場合、または**部分問題の多くが計算不要**な場合。 |

- stack解法については下記のような実装となるよう
```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class NodeWithHeight:
    node: TreeNode | None
    parent: Optional["NodeWithHeight"]
    height: int = -1


class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        def is_leaf(node: TreeNode) -> bool:
            return node.left is None and node.right is None

        if root is None:
            return 0

        nodes_with_height = [NodeWithHeight(root, None, -1)]
        while nodes_with_height:
            node_with_height = nodes_with_height[-1]
            if node_with_height.height != -1:
                if node_with_height.parent is None:
                    return node_with_height.height
                node_with_height.parent.height = max(
                    node_with_height.parent.height, node_with_height.height + 1
                )
                nodes_with_height.pop()
                continue
            if is_leaf(node_with_height.node):
                node_with_height.height = 1
                continue

            left = node_with_height.node.left
            right = node_with_height.node.right
            if left is not None:
                nodes_with_height.append(NodeWithHeight(left, node_with_height, -1))
            if right is not None:
                nodes_with_height.append(NodeWithHeight(right, node_with_height, -1))
```
- TreeNodeクラスに加えてNodeWithHeight独自クラスなるものを定義し使用
  - parentフィールドの型が`Optional["NodeWithHeight"]`となっている点について、"NodeWithHeight" (文字列リテラルによる参照)というものが使われていた
  - Geminiによると、順方向参照(クラスの定義内で、そのクラス自身を参照する場合や、まだ定義されていないクラスを参照する場合)に使用するよう。Pythonの実行時では、その型がまだ定義されていないため、単純な型名で書くとエラーになる。文字列として渡すことで、型チェッカー（Mypyなど）が後で解釈できるようにする、とのこと。
  - `Optional["NodeWithHeight"]`を`"NodeWithHeight | None`と書けないのは、python3.10以降に未対応だから？

- レビューコメントからフィードバック

```python
from typing import Optional
from dataclasses import dataclass

@dataclass
class NodeWithHeight:
    node: TreeNode | None
    height: int = 0


class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        def is_leaf(node: TreeNode) -> bool:
            return node.left is None and node.right is None

        if root is None:
            return 0

        nodes_with_height = [NodeWithHeight(root, 1)]
        max_height = 0
        while nodes_with_height:
            node_with_height = nodes_with_height.pop() 
            if is_leaf(node_with_height.node):
                max_height = max(max_height, node_with_height.height)
            
            left = node_with_height.node.left
            right = node_with_height.node.right

            if left is not None:
                nodes_with_height.append(NodeWithHeight(left, node_with_height.height + 1))
            if right is not None:
                nodes_with_height.append(NodeWithHeight(right, node_with_height.height + 1))
        
        return max_height
```
